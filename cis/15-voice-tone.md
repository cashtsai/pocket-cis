## 15. 文案與語氣 Voice & Tone

品牌一句話:**直接、可靠、不囉嗦。** 你口袋裡的 AI agent —— 隨叫隨到,
有話直說,沒事安靜。

### 15.1 三聲(擴寫)

| 聲 | 規格 |
|---|---|
| **字的聲音** | display/聊天 = jf open 粉圓(圓潤親切,像玩具又不幼稚);正文 = 系統字(閱讀舒適優先);wordmark = Luckiest Guy 只在品牌時刻。自然大小寫,不全大寫吼人 |
| **形的聲音** | 膠囊鈕、泡泡圓角 14、發話側缺角 6、細邊、柔影 —— editorial:軟、安靜、有彈性 |
| **話的聲音** | 人話、短句、給下一步。狀態「沒有壞消息就安靜」;緊急態直亮不猶豫;錯誤留痕不遮醜 |

### 15.2 繁中為主、三語規則(l10n 守門)

- 支援三語:**zh-Hant(源語言)/ en / zh-Hans**。source = 繁中,
  **key 即程式碼裡的繁中字面值**。
- 這個機制的陷阱:漏翻**靜默退回繁中**,不報錯不顯示 key —— 英文使用者看得到,
  CI 看不到。所以守門交給 l10n coverage script(掃三類漏翻:型別掉進 verbatim /
  沒進 catalog / catalog 缺 en),**出貨管線強制,未過不上傳**。
- 文案寫作次序:先寫好繁中(它是正典),en/zh-Hans 翻譯跟上;
  新 UI 字串一律走 catalog,豁免要逐行標記。
- 粉圓字族只覆蓋 zh-Hant 與拉丁語系;zh-Hans 介面整軌落系統字(§4.1)。

### 15.3 進行態:現在分詞

按鈕與狀態的「正在做」一律用「…中」持續態 + 刪節號,做完換回原詞:

> 停止 → **停止中…**;重新檢查 → **檢查中…**;同步中…;重新連線中…

進行中的按鈕同時 disabled + muted(「停止中…」範式),不讓人連打。

### 15.4 破壞性確認:講清楚失去什麼

- 可後悔的(結案/擱置/封存)**不擋確認框**,走 5 秒 Undo(§14.4)。
- 不可後悔的才確認,且**內文必須講具體後果**(會刪掉什麼、幾筆、是否可復原),
  確認鈕用**動詞**(「刪除」「登出並解除配對」),不用「確定」;destructive 紅。
- 失效狀態明說:「此請求已失效,無法回覆」—— 不讓人按一顆沒用的鈕。

### 15.5 相對時間:日界規則

**刻意不用「3 小時前」**這種會持續過期的說法 —— 時間戳寫了就穩定:

| 情境 | 格式 | 例 |
|---|---|---|
| 今天 | `HH:mm` | 14:32 |
| 昨天 | 昨天 HH:mm | 昨天 14:32 |
| 今年更早 | 月/日(locale 排序) | 11/2 |
| 跨年 | 年/月/日 | 2025/12/31 |

- 重繪只排在**下一次顯示會變的時刻**(明天 startOfDay;DST 安全);
  前天以前永遠穩定,零喚醒(§12.3)。
- 動作列時間標籤:今天 `HH:mm`、更早 `M/d HH:mm`。
- 限額 reset 同規:今日 `HH:mm`、跨日 `M/d HH:mm`(§13.4)。

### 15.6 人話 footer 原則

設定列、開關、危險區:**一列一句人話 footer,說人能懂的後果**。

> 範式(抄自現行文案的句法):「帳號只存在主機上,我們不經手。」
> 「發生錯誤時會自動記在這裡,並同步到後端供檢查。」

句法:主詞是東西或結果,不是系統;一句講完;必要時補「所以你可以/不用…」。

### 15.7 文案句式庫(抄自出貨文案的範式)

| 情境 | 句式 |
|---|---|
| 空狀態標題 | 「沒有 X」「尚無 X」「還沒看到 X」(人話陳述,不用技術詞) |
| 空狀態副標 | 「X 會出現在這裡」+ 觸發條件/下一步 |
| 載入錯誤 | 「X 暫時無法取得」+ 原始錯誤 + 重試 |
| 等待他人/系統 | 「等待你回應」「子程序在等你」「已排入下一輪 · 這輪執行完才處理」 |
| 離線 | 「離線 — 顯示快取內容,輸入會在恢復後送出」(現狀+輸入去向,一句講完) |
| 限額 | 「已達用量上限,15:00 可重試」(不知道就說「稍後」,不編造) |
| 疑似異常 | 「疑似卡住:回合開著,但超過 5 分鐘沒有新事件」(說判準,不裝死也不嚇人) |
| 下一步指路 | 「在你的 Mac 打開…,依…裝好並登入後,這個頁籤就會啟用。」(地點→動作→結果) |
| Undo | 「已結案「X」」/「已結案 N 個」+「復原」 |

### 15.8 禁語

- 「發生錯誤」「操作失敗」等無資訊通用句(錯誤要留痕,§14.3)。
- 「確定」當破壞性確認鈕。
- 技術行話進一般 UI(wire 欄位名、HTTP 狀態碼直接示人;除錯資訊收進診斷頁)。
- 驚嘆號堆疊與道歉連發 —— 直接說現狀和下一步就好。
