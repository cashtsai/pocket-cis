> Pocket 設計規範 v1.1 新章(2026-11-14)。間距階抄自 app repo 的 `PocketSpace` token 定義;各「慣例值」為**歸納自現行實作**的呼叫點頻率統計(iOS 與 Android 雙端),標注【歸納】。全章索引見 [cis/README.md](README.md)。

## 10. 間距與格線 Spacing & Grid

### 10.1 4pt 基準階(token 定義)

`PocketSpace`(iOS)/ 同階 dp(Android)/ px(web),**4pt grid**:

| token | 值 | 慣用場合【歸納】 |
|---|---|---|
| s1 | 4 | 微距:icon 與字的貼靠、行內元素垂直收縮 |
| s2 | **8** | **元件內部主力間距**(stack spacing 最高頻) |
| s3 | **12** | 元件群間距、清單內縮 |
| s4 | **16** | 卡片內距、頁邊距、區段內距 |
| s5 | 20 | 區段上緣 |
| s6 | 24 | 大區段間距、區段 header 水平內距 |
| s8 | 32 | 頁級留白 |
| s10 | 40 | 頂級留白(hero、空狀態) |

現頻統計【歸納自現行實作】:主力是 **8 / 12 / 16** 三檔(s2 > s3 > s4),
4 收微距、20/24/32 收區段大距。非階值(6、10、14)見 10.4。

### 10.2 頁邊距

| 場合 | 值 | 備註 |
|---|---|---|
| 頁面/卡片水平邊距 | **14 或 16** | 事實標準【歸納】:14 是 Pocket 偏好的「略窄於 16」editorial 感;新畫面擇一後整頁一致 |
| 清單內縮 | 10 或 12 | 【歸納】 |
| 區段 header | 水平 24 / 上 20 / 下 16 | 元件庫定值 |
| web 內容欄 | max-width `min(760px, 92%)` | 訊息泡同款(§6.3) |

### 10.3 列表行高箱

| 項 | 值 |
|---|---|
| **列最小高度** | **44pt**(`minHeight: 44` 統一守門;= 觸控目標下限) |
| 列垂直 padding | 6–10(行)【歸納】;行內元素(膠囊、badge)2–4 |
| 列水平 padding | 10–14【歸納】 |
| 整列可點 | `contentShape(Rectangle())` 讓整塊(含透明間隙)命中 |

macOS 桌面密度例外:清單列 36pt(游標精度高於拇指),見 [18-platforms.md](18-platforms.md)。

### 10.4 半檔值(6 / 10 / 14)的地位

現行實作大量使用 6、10、14(stack spacing 6 幾乎與 8 同頻;水平邊距 14 是最高頻)
【歸納】。裁定:**承認為「半檔」**—— 元件內部的光學修正值(膠囊內距、icon 字距),
允許使用但不入 token 階;**版面級間距(頁邊、區段、卡片內距)只准用 10.1 的階值或
14/16 頁邊距慣例**,不得拿半檔亂湊。

### 10.5 元件標準內距(元件庫定值)

| 元件 | 內距 |
|---|---|
| 膠囊鈕 / pill | 水平 16 / 垂直 8 |
| 輸入框 | 水平 14 / 垂直 11 |
| badge | 水平 8 / 垂直 3 |
| 卡片容器 | 16 |
| 狀態膠囊 | 水平 12 / 垂直 6(內部動作鈕:水平 10 / 垂直 4) |
| WorkingBar | 水平 16 / 垂直 11 |

### 10.6 格線

Pocket 無多欄雜誌格線 —— 主版型是**單欄內容流 + 側欄**:

- 行動端:單欄,寬度 = 螢幕 − 2×頁邊距;對話內容最寬 540pt(iOS)。
- web console:側欄(sunken 底)+ 單欄內容 `min(760px, 92%)` 置中。
- macOS:三欄 `NavigationSplitView`(Sidebar ~200pt / 內容 / Inspector 280pt),
  見 [18-platforms.md](18-platforms.md)。
- 對齊一律貼 4pt grid;視覺光學修正(偏移 1–3pt)允許,但不得改變盒子尺寸階。

### 10.7 Android / web 對位

- Android 間距分佈與 iOS 刻意對齊(14/16 水平主力、6/8 間距主力)【歸納】;
  現無獨立 spacing token 檔,**v1.1 待辦:抽同名 token**(見 ROADMAP)。
- web:同階 px(4/8/12/16/20/24/32/40),css var 命名 `--space-*` 預留。
